import { Card, CardGrid } from '@astrojs/starlight/components';

<CardGrid>
  <Card title="One shared stack" icon="seti:db">

- MySQL, Redis, OpenSearch and Mailpit run once for every project.
- Each project runs one small PHP container (php-fpm with nginx or apache).
- Ten projects cost about ten php-fpm processes, not ten databases.

</Card>
  <Card title="Ready for real apps" icon="rocket">

- PHP 7.4 to 8.6.
- Composer, Node.js, pnpm, Yarn, wp-cli and n98-magerun2 in the image.
- Detects the framework, then sets up the database, HTTPS domains and mail capture.

</Card>
  <Card title="Your config travels with the repo" icon="document">

- `.lodev/config.yaml` holds the project's settings, hooks, cron and extra services.
- Personal toggles such as Xdebug stay in the uncommitted `config.local.yaml`.

</Card>
</CardGrid>
